- [x] 首页清晰呈现“知行合一”与“知而思、思而行、行而成”，三个阶段不是导航栏目。
- [x] 首页 Now 与 Praxis 项目内容反映当前真实进度，没有把尚未部署写成已经上线。
- [x] 正式内容为三篇真实实践记录：项目 `content/projects/praxis.md`、笔记 `content/notes/ai-code-security-review.md`、日志 `content/journal/what-green-gates-miss.md`，没有发布测试 fixture 或虚构文章。

## SEO 与发现性

- [x] 首页、知识总览与五个知识入口、知识详情、项目、旅程、关于和兼容项目详情具有正确的 title、description 和 canonical URL。
- [x] 所有公开页面输出 Open Graph、Twitter card 与 RSS autodiscovery。
- [x] 知识详情与兼容项目详情输出 article 类型、发布时间、更新时间和标签元数据。
- [x] `/rss.xml` 只包含三项真实、非草稿内容，使用新的知识 canonical、稳定项目 URL 与 `contentId` GUID。
- [x] Sitemap 包含首页、知识总览、五个知识入口、两项知识详情、项目单页、兼容项目详情、旅程与关于；不包含五个 legacy compatibility 地址、404、RSS、robots 或生成 JSON。
- [x] `/blog`、`/notes`、`/journal` 及两项既有知识详情旧地址生成带 `noindex`、目标 canonical 与即时跳转的静态 compatibility page。
- [x] `/robots.txt` 允许公开抓取并指向 Sitemap。
- [x] 404 返回 HTTP 404，输出 `noindex, nofollow`，且不进入 Sitemap。
